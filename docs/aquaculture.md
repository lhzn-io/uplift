# Anchor Deployment: Aquaculture

This document describes the context and variables for our upcoming aquaculture deployment.

## Goal
Measure the causal impact of the AI decision support agent on farm operators' daily production and yield efficiency. Provide predictive maintenance alerts to prevent equipment failure.

## Metrics
- **Treatment:** Farm operators using the Sovereign Stack UI for queries.
- **Control:** Operators proceeding with traditional manual standard operating procedures.
- **Outcome:** Weekly yield mass (higher is better), optimal production volume, and positive incident resolution time.

Aligns with our evaluation tracking as specified in `docs/methodology.md`.
